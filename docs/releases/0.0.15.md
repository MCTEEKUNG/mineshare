# MineShare 0.0.15 candidate

- Settings now includes per-user Start with OS controls for Windows and Ubuntu.
- Windows preserves the existing startup task, including its Administrator level.
- Ubuntu preserves existing desktop-entry commands and detects the optional
  Typeless ordered launcher rather than overwriting it.
- Appearance defaults to System on new installations and follows OS color changes;
  existing explicit Light/Dark choices remain unchanged.
- No input protocol, pairing-key or file-transfer format changes.

Build and installer acceptance must pass before local deployment. This candidate
is not a public release until separately approved. Physical logout/login startup
and native OS theme acceptance remain separate from unit tests.
