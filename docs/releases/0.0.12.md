# MineShare 0.0.12

Windows 11 and Ubuntu desktop release. Update both peers together and verify the
build identity after reconnecting; input protocols and capabilities must match.

## Highlights

- Input and keyboard-routing hardening, including Windows modifier/shortcut
  handling and recovery of the touch-suppressed cursor on Windows laptops.
- Ubuntu X11 edge crossing checks the actual screen boundary before switching.
- Optional Ubuntu keyboard-broker startup ordering for coexistence with Typeless.
- Per-user Ubuntu desktop autostart and refreshed application icons.
- Updated documentation and the round-mascot desk workflow illustration.
- CI covers Windows, Ubuntu 22.04 and Ubuntu 24.04; native Rust caches are isolated
  by runner OS version.

## Install

- Windows x64: use the `*-setup.exe` installer, or the `.msi` alternative.
- Ubuntu x64: use the `.deb` package (`sudo apt install ./<downloaded-file>.deb`).
  AppImage is an alternative; input permissions must still be configured.
- Compare the downloaded installer's SHA-256 with the corresponding
  `SHA256SUMS-*.txt` release asset before installation.
- Quit MineShare before updating. Do not run the standalone daemon alongside the
  GUI. Log out/in when Ubuntu input-group membership changes.

## Important limitations

- Installers are not code-signed; Windows SmartScreen may warn.
- CI compilation/tests are not a physical hardware or Wayland acceptance test.
- Native Windows Precision Touchpad contact gestures are not implemented on Linux.
- Typeless keyboard-broker setup is opt-in; follow the ordered startup guide and
  validate Right Alt routing on your own devices.
- The verified Ubuntu GNOME Alt+Shift language-switch fix is a desktop preference,
  not a setting silently applied by this installer. The physical-keyboard test on
  the affected X11 desktop passed; see [Ubuntu readiness](https://github.com/MCTEEKUNG/mineshare/blob/v0.0.12/docs/ubuntu-readiness.md).

See [Ubuntu broker setup](https://github.com/MCTEEKUNG/mineshare/blob/v0.0.12/docs/linux-typeless-keyboard-broker.md)
for prerequisites. If the update causes a regression, quit the app and reinstall
the previously working installers on both peers; retain your configuration and
logs for diagnosis.
