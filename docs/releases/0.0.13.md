# MineShare 0.0.13

Windows installer update: the `.msi` and `-setup.exe` downloads now use the same
MSI payload and Windows Installer product registration. The EXE is a bootstrapper,
not a second NSIS application installation.

- Detect existing MSI, older NSIS/per-user and script-only installations.
- Show an explicit Update flow when a previous installation is found.
- Reuse the existing directory, pairing/configuration and startup preferences.
- Retire a verified old NSIS registration only after MSI installation succeeds.
- Remove verified duplicate legacy shortcuts only when a replacement exists.
- Preserve the MSI upgrade identity; reject version downgrades.
- Include automated disposable-Windows upgrade and rollback acceptance tests.

Quit other installer windows before updating. An active MineShare process may
close briefly; user data is not an installer-owned resource. A new installation
does not silently opt users into startup. Existing enabled or disabled startup
tasks and Run entries are retained.

Windows installers are still unsigned. Review SmartScreen warnings and verify
SHA-256 using the attached manifests. Update both peers to the same release.

Ubuntu packaging remains available; native Linux touchpad and other limitations
are described in [Ubuntu readiness](https://github.com/MCTEEKUNG/mineshare/blob/v0.0.13/docs/ubuntu-readiness.md).
