# MineShare 0.0.16

LAN discovery lists computers without pairing automatically. Choose a computer,
confirm Send request, and accept or decline on the receiver. First-time pairing
still verifies a PIN after acceptance. Previously trusted destinations require
approval when selected explicitly, but skip the repeat PIN exchange. Both apps
must use `control-v3`; previous identities and trust entries are preserved.

Home also offers Cancel pairing request and Disconnect & pause / Resume controls.
Requests and PIN submissions are scoped to the current attempt and cleared on
teardown. Declined, cancelled and failed new requests do not retry automatically.

The selected trusted peer retains its reconnect target when an mDNS advertisement expires
during a LAN outage. While disconnected and not manually paused, MineShare refreshes
discovery every 5 seconds and follows local interface/IP changes automatically.
Pairing and network setup have bounded deadlines; a disconnected socket is also
noticed while waiting for the user to enter a PIN.

MineShare still connects one peer at a time. The installer upgrades the existing
installation and preserves pairing, settings, and the existing startup preference.

Linux mouse capture now remains available if Typeless already owns a keyboard
interface during an in-session upgrade. A failed keyboard group releases its
partial ownership without stopping independent mouse capture or publishing false
keyboard readiness. See [the physical handoff verification](../ubuntu-mouse-handoff.md).

See [connection controls and physical acceptance steps](../connection-controls.md).
